# Installation

## Via the Kwirth marketplace

Webamp is published in the **jfvilas marketplace**. If your Kwirth does not list it yet, add this
manifest as a marketplace first:

```
https://raw.githubusercontent.com/jfvilas/kwirth/master/manifest.json
```

1. Go to **Settings → Plugins → Marketplace**
2. Find **Webamp**
3. Click **Install**
4. Add the Webamp channel to any cluster view

## Manual installation

If you need to install manually:

1. Download the plugin package (`@jfvilas/kwirth-plugin-webamp`)
2. Place it in the Kwirth plugins directory
3. Restart Kwirth
