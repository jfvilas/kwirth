# NOTICE

## Webamp

The Webamp library (`src/front/webamp/webamp.txt`, bundled into `front.js`) is a UMD bundle of
Webamp 2.3.1 by Jordan Eldredge (github.com/captbaritone/webamp), distributed under the MIT license.
Its full text is in `LICENSE.webamp` and must be kept.

Webamp is a Winamp 2 clone written in pure JavaScript. The Milkdrop visualizer
module (which uses WebAssembly) is intentionally excluded.

## The rest of the plugin

The channel, the back end and the iframe machine around Webamp are this plugin's own.
