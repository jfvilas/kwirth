# Licenses and attribution

## Rally-X plugin

An open source Kwirth plugin, published as `@jfvilas/kwirth-plugin-rallyx`. Source code at
[github.com/jfvilas/kwirth](https://github.com/jfvilas/kwirth) (folder `plugins/rallyx`).

## Game

The Rally-X game is a homebrew recreation of the classic 1980s arcade game Rally-X (originally
by Midway/Namco), developed by Marco Parenzan.

- **Source:** https://github.com/marcoparenzan/rallyx

platform. This plugin extends Kwirth with a game channel.
