# Installation

Rally-X is an **open source plugin** published to npm as `@jfvilas/kwirth-plugin-rallyx`, and listed in
the **jfvilas marketplace**.

## Prerequisites

- Kwirth 0.6.x or later

## Install

1. If your Kwirth does not list the jfvilas marketplace yet, add this manifest as a marketplace:

   ```
   https://raw.githubusercontent.com/jfvilas/kwirth/master/manifest.json
   ```

2. Open the **plugin manager**, find **Rally-X** in that marketplace and click **Install**.

## Verify

The Rally-X channel appears in the channel selector when adding a new tab.
