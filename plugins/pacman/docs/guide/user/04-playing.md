# Playing

1. Start the channel (⚙ → **Start** → **OK**)
2. **Click the game area** — the game needs the keyboard
3. Press `Space` to insert a coin, then `1` for one player or `2` for two
4. Move Pac-Man with the arrow keys

## The bar above the game

| Item | Meaning |
|---|---|
| **Score** | The score of the game in progress |
| **Lives** | The lives left. In practice mode they are infinite, shown as `∞` |
| **Level** | The level being played |
| **Best** | The best score: the table's first place, or a better one made in this session |
| **paused** | Shown while the game is paused |
| **?** | Opens this page |

## Pausing

- **⚙ → Pause / Resume** pauses and resumes the game. A pause asked from the menu stays until you
  resume it.
- With **Pause when the tab loses focus** on, the game pauses by itself when you click outside it or
  switch to another tab or window, and resumes when you click the game again.

## Fullscreen

Press `Ctrl` `Alt` `F11` to play in fullscreen, and again to leave it. It works also while the game has
the keyboard. In fullscreen, a bar at the top shows the plugin's icon, the channel and the cluster.

## Switching tabs

You can switch to another Kwirth tab at any time: the game is hidden but kept. Come back to the Pac-Man
tab and it is where you left it.
