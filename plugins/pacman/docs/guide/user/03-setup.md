# Add and configure the channel

## Adding the channel

1. Select your cluster
2. Select the view **none** (Pac-Man is autonomous — it does not read cluster resources)
3. Select the channel **pacman**
4. Click **ADD**

## Setup dialog

When you click **Start** on the tab (⚙ → **Start**), the setup dialog appears:

| Field | Meaning |
|---|---|
| **Notify a sender when the record is beaten** | A sender and one of its configurations (mail, chat, ticketing…). When a game takes the first place of the table, it gets a message saying who did it, the score, the level and who held the record before. **Do not notify** is the default |
| **Pause when the tab loses focus** | Pauses the game while the keyboard is neither in the game nor in its tab, and resumes it when you come back. On by default |
| **Set as default** | Remembers these values for the next Pac-Man channels |

Click **OK** to start the channel.
