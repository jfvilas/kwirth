# High scores

The **High scores** table, next to the game, shows the ten best games of this Kwirth: the player, the
score and the level.

## Entering the table

When a game ends, and its score is good enough for the table — there is room left, or it beats the
last entry — the panel says **"&lt;score&gt; points — you made the table"** and offers to save it under
your Kwirth user name. A score that does not make it is not offered.

## Shared by everyone

The table lives in the cluster, not in your browser: every user of that Kwirth sees the same one, from
any machine. If the channel has no connection to the back end, the score is kept in the browser
instead.

## The record

If the channel was set up with a sender, beating the first place sends a message through it.
