# Licenses and attribution

## Pac-Man plugin

An open source Kwirth plugin, published as `@jfvilas/kwirth-plugin-pacman` under the **GPL v3** (the
license of the game it bundles). Source code at [github.com/jfvilas/kwirth](https://github.com/jfvilas/kwirth)
(folder `plugins/pacman`).

## Game

The game is the Pac-Man remake by **Shaun Williams** (https://github.com/shaunew/Pac-Man),
Copyright © 2012 Shaun Williams, distributed under the GNU General Public License version 3. Based on
the original works of Namco, GCC and Midway; research by Jamey Pittman and Bart Grantham.

The plugin adds a small bridge inside the game, to report the score and to pause it, and a script next
to it that hands Kwirth's fullscreen shortcut to the page. Nothing else in the game is changed.

## Kwirth

[Kwirth](https://kwirthmagnify.dev) is an open source Kubernetes observability and operations platform.
This plugin extends it with a game channel.
