# Installation

Pac-Man is an **open source plugin** published to npm as `@jfvilas/kwirth-plugin-pacman`, and listed
in the **jfvilas marketplace**.

## Prerequisites

- Kwirth 0.6.x or later

## Install

1. If your Kwirth does not list the jfvilas marketplace yet, add this manifest as a marketplace:

   ```
   https://raw.githubusercontent.com/jfvilas/kwirth/master/manifest.json
   ```

2. Open the **plugin manager**, find **Pac-Man** in that marketplace and click **Install**.

Its guide (this one) is published next to it as `@jfvilas/kwirth-docs-pacman`.

## Verify

The `pacman` channel appears in the channel selector when the view is `none`.
